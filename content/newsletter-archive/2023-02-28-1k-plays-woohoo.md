SciArt of the month - Feb 2023

This science art piece shows cell nuclei that contain DNA in the eye of a developing zebrafish. The nuclei were stained using DAPI staining that binds to the DNA, imaged with a state-of-the-art AiryScan microscope, and the images were subsequently processed. Using biomedical image analysis to extract, separate, and depth-code these data, we can start to see nuclei closer to the viewer in black, and those further away using an image gradient like red-green-blue-cyan-magenta and finally the yellow, which is furthest in the tissue. These data help us understand how the eye is formed. Check out more here: <https://twitter.com/Zeeks_Art>

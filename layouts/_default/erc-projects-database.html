FAQ

How can I filter the projects?

Search by project title, acronym, researcher name, host institution, country or panel code, and filter by call year, grant scheme and domain. Search and filters work together.

What does each project card show?

Each project card shows the scientist's name, host institution, country, project title, acronym, and a CORDIS link to read more.

Change log

21 September 2026

  • Dataset refreshed from a new ERC dashboard export. The database now holds 12,133 projects, up from 11,907.
  • Total EU contribution shown in the summary strip updated to €22,062M, from €21,485M.
  • 226 projects added, almost all 2025 calls and Advanced Grants. No projects were removed.
  • Project titles cleaned: stray line breaks and double spaces removed from 540 titles, so cards now read on a single clean line.
  • Host institution names cleaned: internal institution ID codes no longer appear in the multi-institution listings on Synergy Grant cards.
  • Added a search box above the results, searching project title, acronym, researcher name, host institution, country, panel code and call code.
    • Typing more than one word returns projects matching every word, not any of them. Searching cancer biology returns 9 projects, not the 567 that mention either word.
    • The words do not have to sit together or be in the same field. cancer biology also finds a project whose title says biology at an institute with cancer in its name.
    • Search and filters work together: a search narrows whatever filters are already ticked, and the counts beside each filter drop to match.
    • Matching is on part-words, so plank will not find Planck, but Planck finds every Max Planck project.
    • Your search is added to the page address, so a set of results can be bookmarked or sent to someone.
    • Abstracts are not searched. Only the fields listed above.
  • Project cards now carry a third tag with the ERC evaluation panel — LS1, PE8, SH3, and LS, PE or SH for Synergy Grants. Hover it to see the full panel name.
  • The call year and grant scheme filters now read the ERC call code on each project (ERC-2025-STG gives 2025 and Starting Grant), and the domain filter reads the evaluation panel. Filter options are built from the projects themselves, so a new call year appears on its own once it is funded.
